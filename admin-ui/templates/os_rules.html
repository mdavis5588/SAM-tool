How a rule is chosen
  1. An exempt installation requires nothing, whatever the rules say.
  2. A guest whose hypervisor holds a Virtual Datacenter or unlimited-guest subscription requires nothing — that is what such a subscription buys. This depends on the guest's hypervisor host being set on its OS page.
  3. Any other guest takes the vendor's per-guest rule. A guest is identified by its virtual flag, never by its distribution name: a RHEL guest reports the same string as a RHEL physical host.
  4. A physical host takes the rule whose pattern matches its reported distribution — the most specific match wins.
  5. Overriding all of the above: if a line is already assigned to the host, that line's metric is used. Virtual Datacenter is a purchasing decision discovery cannot see, so without this a VDC host would be counted per socket pair.
Before you rely on a number

These rules reflect each vendor's published packaging as recorded, and vendors change packaging. Confirm against the current price list before using a count in a true-up or an audit response.

A host reported as No rule contributes nothing to the required total. That is not the same as needing nothing — the requirement is unknown, and the summary understates the estate until the rule exists.
